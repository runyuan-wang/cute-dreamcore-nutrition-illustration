# Motif Library

| Motif | Meaning | Inclusion rule |
|---|---|---|
| Hero floating island | central educational ecosystem | always for poster/section concepts |
| Satellite food island | source or example | one per major food group, avoid clutter |
| Cloud path | educational direction | always when more than one island exists |
| Mushroom guide | friendly orientation | default on |
| Microbe sprites | symbolic ecosystem residents | only when claim supports microbiome context |
| Moon or soft sun | time and atmosphere | one, never ominous |
| Garden bridge | connection and continuity | subtle Chinese-inspired accent |
| Auspicious-cloud curve | atmosphere | use sparingly and originally |
| Blank science board | overlay anchor | reserve for title/callouts, no random text |
| Stars and flowers | collectible detail | decorate edges and paths, not every gap |
