# Named Palette

| Name | Hex | Use |
|---|---|---|
| Cloud Cream | `#FFF8EC` | sky and safe zones |
| Milk White | `#FFFDF8` | highlights |
| Misty Sky Blue | `#CFE8F5` | background |
| Soft Lake Blue | `#AFCFE3` | clouds and bridges |
| Mint Bean Green | `#CDE8D1` | gardens |
| Nutrition Green | `#7EBB91` | healthy ecosystem accents |
| Sweet Peach | `#F6B7A5` | food characters |
| Soft Coral | `#EF8F7C` | gentle emphasis |
| Custard Yellow | `#F8D98B` | stars and grain |
| Dream Lavender | `#DCCDEE` | moonlight |
| Mushroom Beige | `#DABF9E` | guide character |
| Deep Teal Text | `#315B61` | accessible text |
| Soft Ink Gray | `#59676B` | secondary text |

Keep the palette creamy, pastel, bright enough for education, and never neon, muddy, or gloomy. Text overlays should use Deep Teal Text or Soft Ink Gray over Cloud Cream/Milk White panels, with contrast checked programmatically.
